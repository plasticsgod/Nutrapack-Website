FAQ

Security feature questions

What are security features?

Protection built into the label, seal or band you already use: tamper-evident VOID materials, micro text, anti-copy patterns and custom holographics, designed around your brand.

Can a counterfeiter copy it?

Tier 2 and 3 features are chosen because a scanner or copier can't reproduce them. On a copy the holographic color shift is lost, micro text blurs and anti-copy patterns break apart, so a fake is easier to spot.

Which formats can carry them?

Pressure-sensitive labels, neck bands, shrink bands, tamper seals and tip-ons, plus applications like cartons, tubs and spirits bottles.

Do I need to protect every SKU?

No. Start with one SKU and add tiers as risk grows.
