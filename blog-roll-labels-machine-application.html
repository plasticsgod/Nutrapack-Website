Roll Labels for Machine Application: What Your Co-Packer Needs

Labels that don’t fit the labeling machine stop the line. Confirm these specs with your co-packer before anything is printed.

Pressure-sensitive labels for products are usually supplied on rolls, ready for a labeling machine at your co-packer. The artwork can be perfect, but if the rolls don’t match the machine, the line stops. These are the specs to confirm first.

Core size

The core is the cardboard tube in the middle of the roll. Machines are set up for a specific core inside diameter. Larger cores are common on automatic labelers and smaller cores on hand-held or desktop applicators. Ask your co-packer which one their machine takes.

Maximum roll diameter

Each machine has a limit on how big a roll it can hold. That decides how many labels fit on each roll, and how often the operator changes rolls.

Unwind direction

Labels can come off the roll in different orientations: top first, bottom first, right side first, left side first, with the print facing in or out. Printers number these positions. If the orientation is wrong, every label goes on sideways or upside down, so get the exact position from your co-packer, ideally as a diagram.

Label gap and number across

The gap between labels and whether labels run one or two across the web both need to match what the machine’s sensor and applicator expect.

Material and adhesive

  • Squeezable or curved containers need a material that flexes without wrinkling or lifting.
  • Cold or wet conditions, like fridges, ice buckets and condensation, need an adhesive rated for them.
  • HDPE tubs and bottles are low-energy plastics, so the adhesive has to be suited to them.

Artwork checks

  • Leave a safe zone away from the label edges for text.
  • Make sure your barcode or QR code won’t wrap around a tight curve.
  • Confirm the label size against the container’s label panel, not just the container height.
